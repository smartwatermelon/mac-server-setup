# LaunchAgents and LaunchDaemons

This page lists every launchd job that the repo installs, derived from the plist templates in `app-setup/templates/` and the plist heredocs in `app-setup/*.sh` and `scripts/server/*.sh`.

`<hostname>` is the lowercase server name (`SERVER_NAME` in [config keys](config-keys.md)). `~operator` is the home folder of the operator account. `~admin` is the home folder of the admin account that runs the setup scripts.

## LaunchDaemons

LaunchDaemons live in `/Library/LaunchDaemons/` and start at boot, with or without a login. They run as root unless the plist sets `UserName`.

## LaunchAgents

LaunchAgents live in `~/Library/LaunchAgents/` of the account in the "Runs as" column. They start only when that account has a GUI login. The operator account logs in automatically at boot.

| Label | Runs as | What it runs | Schedule | Log path | Installed by | Plist source |
| --- | --- | --- | --- | --- | --- | --- |
| `com.<hostname>.operator-first-login` | operator | `~operator/.local/bin/operator-first-login.sh`, once. The script moves its own plist out of `LaunchAgents` when it finishes. | RunAtLoad | `~operator/.local/state/com.<hostname>.operator-first-login.log` | [`scripts/server/setup-application-preparation.sh`](https://github.com/smartwatermelon/mac-server-setup/blob/main/scripts/server/setup-application-preparation.sh) | Heredoc in `setup-application-preparation.sh` |

## Jobs that Homebrew installs

The repo does not write these plists. It runs `brew services start logrotate`, and Homebrew writes its own LaunchAgent.

| Service | Runs as | Started by |
| --- | --- | --- |
| `logrotate` (Homebrew service) | admin | [`scripts/server/setup-log-rotation.sh`](https://github.com/smartwatermelon/mac-server-setup/blob/main/scripts/server/setup-log-rotation.sh) |
| `logrotate` (Homebrew service) | operator | [`scripts/server/operator-first-login.sh`](https://github.com/smartwatermelon/mac-server-setup/blob/main/scripts/server/operator-first-login.sh) |
