# Reference

These pages list facts about the stack in tables, derived from the repo's code.

- [Config keys](config-keys.md): every key in `config/config.conf.template`, with its default.
- [LaunchAgents and LaunchDaemons](launchagents.md): every launchd job that the repo installs, with its account, schedule and log.
- [Log files](logs.md): every log file that the scripts and launchd jobs write.
- [Ports](ports.md): every TCP port that the stack listens on or connects to.
- [Scripts](scripts.md): every script in the repo, where it runs, and as which account.
- [Stack matrix](stack-matrix.md): each part of the stack, whether it is required, optional or replaceable, and the config keys it needs.
- [Glossary](glossary.md): the terms that you meet in these docs.
